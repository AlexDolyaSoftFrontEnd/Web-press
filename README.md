# Как работает Интернет

Краткая презентация для **разработчиков**, которая объясняет, как устроен Интернет и как браузер взаимодействует с сервером на практике.

В презентации разобраны:
- что такое Интернет и компьютерные сети;
- роль провайдеров, клиентов и серверов;
- как происходит загрузка сайта шаг за шагом;
- основы HTTP/HTTPS, DNS, IP и доменов;
- связь сетевых основ с современной веб-разработкой.
