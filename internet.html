Что такое Интернет

Интернет — это глобальная распределённая сеть, объединяющая миллиарды устройств для обмена данными по единым правилам.

Из чего состоит Интернет

  • Конечные устройства (клиенты и серверы)
  • Каналы передачи данных
  • Сетевые протоколы
  • Программные системы

Компьютерная сеть

Компьютерная сеть — это минимум два устройства, способные передавать данные друг другу.

  • по кабельному соединению
  • по беспроводной сети
  • через мобильные сети
  • через спутниковую связь

Типы сетей

  • LAN — локальная сеть (дом, офис)
  • WAN — объединение сетей на больших расстояниях.
  • SATCOM — спутниковая связь для удалённых регионов.

Интернет представляет собой крупнейшую WAN-сеть, использующую кабельные, радиоканальные и спутниковые соединения.

Интернет-провайдер

Интернет-провайдер — это сторона, обеспечивающая подключение устройства к глобальной сети.

Сервер никогда не инициирует запрос первым.

Всегда сначала клиент.

Все сетевые запросы проходят через инфраструктуру провайдера.

Функции провайдера

  • Назначение сетевого адреса
  • Маршрутизация запросов.
  • Передача ответов от удалённых серверо.в

Клиент и сервер

Клиент — программа, инициирующая сетевой запрос.

Сервер — система, принимающая и обрабатывающая запросы.

Принцип взаимодействия

Сервер не инициирует соединение самостоятельно.

Инициатором обмена всегда выступает клиент.

Загрузка веб-страницы

  1. Ввод адреса ресурса
  2. Определение сетевого адреса через DNS
  3. Отправка запроса
  4. Получение разметки
  5. Построение интерфейса браузером

Что такое протокол

Протокол — это формализованный набор правил, определяющий формат, порядок и условия обмена данными между системами.

Пример: транспорт и прикладной уровень

  • TCP — обеспечивает надёжную доставку данных, контроль порядка и целостности.
  • API — описывает структуру запросов, ответов и доступные операции. 

Соединение → Передача → Подтверждение

Один уровень отвечает за доставку, другой — за смысл передаваемых данных.

Основные протоколы

  • HTTP / HTTPS — передача веб-ресурсов
  • SMTP / IMAP — электронная почта
  • FTP / SFTP — передача файлов

HTTP

HTTP основан на модели обмена:

  • Запрос
  • Ответ

Запрос:
GET /users/123 HTTP/1.1
Host: api.example.com

Ответ:
HTTP/1.1 200 OK
Content-Type: application/json

{
  "id": 123,
  "name": "Alex"
}

Клиент инициирует запрос, сервер возвращает результат обработки.

HTTPS

HTTPS добавляет криптографическую защиту поверх стандартного обмена.

Соединение шифруется с использованием пары ключей: публичного и приватного.

Публичный ключ доступен клиенту, приватный хранится только на сервере.

Это обеспечивает конфиденциальность, целостность и подлинность данных.

IP-адрес

IP-адрес — уникальный идентификатор устройства в сети.

Пример: 172.217.18.100

Доменные имена

Числовые адреса неудобны для использования человеком.

Доменные имена служат удобным отображением сетевых адресов.

DNS

DNS преобразует доменное имя в сетевой адрес.

Это механизм сопоставления имён и адресов.

Веб-страница в React

В React страница формируется как результат рендеринга компонентов.

Разметка описывается декларативно и обновляется при изменении состояния.

  • Компоненты — базовые элементы интерфейса
  • Состояние — источник данных
  • Свойства — механизм передачи данных
  • Хуки — управление жизненным циклом

Интерфейс является функцией текущего состояния.

Веб-страница в Next

Next дополняет React механизмами серверной генерации страниц.

Формирование интерфейса может происходить на сервере, заранее.

  • Файловая маршрутизация
  • Различные стратегии генерации страниц
  • Выполнение части логики на сервере
  • Оптимизированная загрузка данных

React описывает модель интерфейса (что должно быть) как модель, Next определяет стратегия исполнения (где, когда и как формируется) на этапе его рендеринга и исполнения в браузере.

Современный веб

  • Разделение логики, представления и данных
  • Асинхронное взаимодействие с сетью
  • Гибридные подходы к рендерингу

Итог
