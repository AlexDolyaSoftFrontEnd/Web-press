Что такое Интернет

Интернет — это глобальная сеть, которая соединяет миллиарды устройств и позволяет им обмениваться данными.

Это не «облако», а физическая инфраструктура + правила общения.

Из чего состоит Интернет

  • Устройства (клиенты и серверы)
  • Каналы передачи данных
  • Протоколы (правила общения)
  • Программное обеспечение

Компьютерная сеть

Сеть — это минимум два устройства, которые могут обмениваться данными.

  • по кабелю
  • по Wi-Fi
  • через мобильную сеть

Типы сетей

  • LAN — дом, офис
  • WAN — соединение сетей между городами и странами

Интернет — это самая большая WAN в мире

Интернет-провайдер

Провайдер — это компания, которая подключает ваше устройство к сети.

Браузер не «идёт в Интернет» напрямую — он идёт через провайдера.

Что делает провайдер

  • Назначает IP-адрес
  • Передаёт ваши запросы дальше
  • Получает ответы от серверов

Клиент и сервер

Клиент — браузер или приложение

Сервер — компьютер, который обрабатывает запросы

Важное правило

Сервер никогда не инициирует запрос первым

Всегда сначала клиент

Как загружается сайт (шаги)

  1. Пользователь вводит адрес сайта
  2. Браузер запрашивает IP через DNS
  3. Отправляется HTTP-запрос
  4. Сервер возвращает HTML
  5. Браузер рендерит страницу

Что такое протокол

Протокол — это набор правил, по которым устройства общаются между собой.

Основные протоколы

  • HTTP / HTTPS — веб
  • SMTP / IMAP — почта
  • FTP / SFTP — файлы

HTTP простыми словами

HTTP — это диалог:

  • Запрос (Request)
  • Ответ (Response)

HTTPS

HTTPS = HTTP + шифрование

Защищает данные пользователя

IP-адрес

IP — уникальный адрес устройства в сети

Пример: 172.217.18.100

Зачем нужны домены

IP неудобны для людей

Домены делают адреса понятными

API Endpoint (REST)

https:// api.example.com/ v1/ users/ 123
  • HTTPS — транспортный уровень, безопасность
  • api.example.com — boundary сервиса
  • /v1 — версия контракта API
  • /users — REST-ресурс
  • /123 — идентификатор ресурса

DNS

DNS переводит доменное имя в IP-адрес

Это «телефонная книга» Интернета

Что такое веб-страница

Веб-страница — это документ, который браузер получает по HTTP(S)

Чаще всего это HTML, связанный с CSS, JavaScript и медиа

  • HTML — структура документа
  • CSS — внешний вид
  • JavaScript — логика и интерактивность
  • Assets — изображения, шрифты, видео

HTML

HTML задаёт структуру и семантику веб-страницы

Это основа, на которой строится весь фронтенд

Современный веб

  • JavaScript как слой логики и типизация в TypeScript
  • Работа с API и асинхронными данными
  • SPA, SSR, SSG, гибридные подходы

Почему это важно разработчику

  • Осознанная работа с Network и DevTools
  • Быстрое выявление проблем на клиенте
  • Эффективное взаимодействие с backend
